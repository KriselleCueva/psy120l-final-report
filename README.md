# psy120l-final-report
The Role of Attachment Style in Perceived Romantic Attractiveness and Relationship Expectations: Effects of High vs. Low Communication in Dating Profiles

This repository contains the published HTML version of my PSY 120L final reproducible report. 

This project examined whether romantic attractoin towards high vs. low communicative partner profiles is influenced by the participants' attachment anxiety style. 

This report was created using Quarto and R. 

The published report file is index.html. 

The dataset is not included in this repository.
